# Offline-First Yaklaşımı Nedir?

Mobil uygulamalar genellikle veri çekmek için internet bağlantısına güvenirler. Ancak metroda, kırsal alanda veya internetin zayıf olduğu anlarda uygulamanın işlevini yitirmemesi gerekir. Offline-first mimari, verinin öncelikle yerel veritabanına yazılmasını ve internet bulunduğunda arka planda sunucuyla senkronize edilmesini sağlar.

## Flutter ve Hive NoSQL

Flutter ekosisteminde yerel veritabanı seçeneklerinden biri olan **Hive**, tamamen Dart ile yazılmış oldukça hızlı bir NoSQL veritabanıdır.

```dart
import 'package:hive/hive.dart';

void main() async {
  var box = await Hive.openBox('testBox');
  box.put('name', 'MainX Stüdyoları');
  print('Name: ${box.get('name')}');
}
```

Bu yapı ile kullanıcının verilerini anında cihaza kaydedip, uygulama deneyimini kesintisiz hale getirebiliriz.
